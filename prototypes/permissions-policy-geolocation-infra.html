Geolocation diblokir di production Imah Aing

Ringkasan untuk tim infra / DevOps · 5 Nov 2026

TL;DR

  • Gejala: tombol “Gunakan Lokasi Saya” di form Imah Aing tidak jalan di production. Popup izin lokasi tidak pernah muncul. Di staging normal.
  • Penyebab: response production membawa header Permissions-Policy: ... geolocation=() .... Browser mematikan geolocation untuk seluruh dokumen. Kode web tidak bisa meng-override ini.
  • Sumber header: konfigurasi header response di layer ingress production, bukan di kode web. Lokasi file persisnya dibagikan lewat jalur internal.
  • Permintaan: ubah geolocation=() menjadi geolocation=(self). Satu baris. Efek berlaku ke seluruh host sapawarga.digitalservice.id (lihat bagian 5).

4Perubahan yang diminta

    
Konfigurasi header response di layer ingress. Lokasi file persis dibagikan lewat jalur internal.

    
Wajib production

    
Satu baris pada konfigurasi production:

    

      
  spec:

      
    headers:

      
-     permissionsPolicy: "camera=(), geolocation=(), microphone=(), payment=()"

      
+     permissionsPolicy: "camera=(), geolocation=(self), microphone=(), payment=()"

    

    
Opsional dev

    
Konfigurasi development yang setara, perubahan sama. Staging yang kita pakai ada di Netlify, jadi file ini tidak memengaruhi staging.

    
Camera, microphone, payment tetap (). Belum ada fitur kamera di form Imah Aing yang diverifikasi. Cek dulu sebelum menyetujui apa pun di luar geolocation.

    
Cara deploy dan sync mengikuti proses yang berlaku di infra.

Catatan: modul Imah Aing tidak memakai GOOGLE_MAPS_API. Peta di Imah Aing memakai Leaflet, jadi key Google Maps tidak dipakai di alur ini dan tidak terkait bug. Lokasi pengguna tetap diambil dari navigator.geolocation milik browser, bukan dari penyedia peta. Satu-satunya fitur di tabel di atas yang memakai Google Maps adalah TrackingComplaint (/new-aduan-warga).
